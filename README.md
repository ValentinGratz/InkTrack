# InkTrack

[![Open in Bolt](https://bolt.new/static/open-in-bolt.svg)](https://bolt.new/~/sb1-m9w3etvb)

**InkTrack** est une application web mobile et minimaliste permettant de suivre avec précision la durée de vie des cartouches d'encre de votre imprimante. 

Fini les notes perdues dans un bloc-notes : déterminez exactement combien de temps dure chaque cartouche entre son installation et son remplacement.

## ✨ Fonctionnalités
- **Installation rapide** : Enregistrez une nouvelle cartouche (Noir ou Couleur) avec la date du jour en un clic.
- **Suivi en temps réel** : Visualisez instantanément depuis combien de jours vos cartouches actives sont en place.
- **Calcul automatique** : Lors du remplacement, l'application fige la date et calcule la durée totale d'utilisation.
- **Historique complet** : Conservez une trace propre de vos anciennes cartouches pour analyser votre consommation.
- **Données locales et privées** : Toutes vos données sont sauvegardées localement dans votre navigateur (`localStorage`). Rien ne transite sur un serveur.

## 📲 Comment l'installer sur votre Google Pixel / Android ?

Puisque ce projet est public, vous pouvez l'utiliser comme une vraie application sur votre smartphone grâce à **GitHub Pages** :

1. Sur GitHub, allez dans les **Settings** (Réglages) de ce dépôt.
2. Dans le menu de gauche, cliquez sur **Pages**.
3. Dans la section *Build and deployment*, sous *Source*, choisissez **Deploy from a branch**.
4. Sélectionnez la branche `main` (ou `master`) et le dossier `/ (root)`, puis cliquez sur **Save**.
5. Attendez 1 à 2 minutes : GitHub va vous donner un lien public sécurisé (ex: `https://github.io`).

**Sur votre téléphone :**
- Ouvrez ce lien dans **Google Chrome**.
- Appuyez sur les 3 petits points en haut à droite.
- Sélectionnez **Ajouter à l'écran d'accueil**. Une icône InkTrack apparaîtra aux côtés de vos autres applications !
